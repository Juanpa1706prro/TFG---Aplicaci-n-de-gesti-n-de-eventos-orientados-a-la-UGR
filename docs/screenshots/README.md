# Capturas para el README

Coloca aquí las imágenes referenciadas en el README principal. Formato recomendado: **PNG**, relación **16:9**, ancho ~1280 px.

## Archivos esperados

| Archivo | Contenido sugerido |
|---------|-------------------|
| `01-mapa-eventos.png` | Mapa con marcadores de eventos (captura principal / hero) |
| `02-detalle-evento.png` | Ficha de evento o formulario de creación |
| `03-asistente-ia.png` | Panel del asistente con una conversación de ejemplo |
| `04-perfil-amigos.png` | Perfil de usuario o panel de amigos |
| `05-panel-admin.png` | *(Opcional)* Listado de usuarios o eventos en admin |

## Consejos

- Usa **datos ficticios** (seeds de demo), no información real.
- Misma resolución y tema visual en todas las capturas.
- Oculta DevTools y pestañas personales del navegador.
- No incluyas claves API, cookies ni datos sensibles.

## Cómo capturar

1. Levanta la app: `docker compose up` desde la raíz del proyecto.
2. Inicia sesión con un usuario de demo.
3. Navega a cada pantalla y captura (Win + Shift + S en Windows).
4. Guarda con el nombre exacto de la tabla anterior.

Cuando añadas los PNG, el README los mostrará automáticamente.
